Platform Backup Privacy

Private infrastructure · public disclosure

Encrypted VPS backups to Google Drive.

Platform Backup is a private operator tool that copies encrypted recovery snapshots from a production VPS to its owner's Google Drive.

01

Purpose

The integration protects PostgreSQL databases, application files, and infrastructure configuration against loss of the primary server. It is not offered as a public service and does not provide user registration.

02

Google Drive access

The app requests the narrow drive.file scope. It can create and manage only the Drive files used by this integration; it does not request broad access to unrelated Drive content.

03

Security model

  • Backup contents are encrypted locally with restic before upload.
  • OAuth credentials are kept outside public source control.
  • Restore drills validate that off-site snapshots are usable.

Details about data handling are available in the Privacy Policy.
