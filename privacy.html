Platform Backup Privacy

Last updated October 22, 2026

Privacy Policy

Platform Backup is a private, single-operator integration used to store encrypted infrastructure backups in the operator's Google Drive.

Data accessed

The integration uses Google's drive.file scope to create, read, update, and delete only files and folders created or explicitly opened through the integration. It does not request access to unrelated files in the Google Drive account.

Data stored

OAuth credentials are stored outside public source control in access-restricted configuration files. Backup contents are encrypted locally before they are uploaded to Google Drive. The integration does not operate an analytics service or advertising system.

Use and sharing

Google user data is used solely to authenticate the backup process and manage its encrypted repository. It is not sold, used for advertising, or shared with third parties except infrastructure providers required to operate Google Drive and the source server.

Retention and deletion

Encrypted backup snapshots are retained according to the operator's recovery policy and pruned automatically. The operator can revoke the application's Google Account access or delete the backup repository at any time.

Security

Access is limited through OAuth, restricted host permissions, and client-side encryption. No method of storage is risk-free, so backup integrity and restore capability are tested regularly.

Contact

Questions can be submitted through the project issue tracker.
