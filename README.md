# Platform Backup OAuth

Public homepage and privacy policy for the private `platform-prod-backup`
Google Drive integration.

The site contains no credentials, backup data, server addresses, or private
operational documentation. It is published with GitHub Pages from `main`.

The [site specification](docs/specs/oauth-information-site.md) records the public pages, disclosure boundaries and acceptance checks.

The same Pages site hosts the [Qwen Local Chrome extension privacy policy](https://artembas-web.github.io/platform-backup-oauth/qwen-local/privacy.html) at a separate URL for its Chrome Web Store listing. Its source is the approved policy shipped with Qwen Local for Chrome 0.4.0.
